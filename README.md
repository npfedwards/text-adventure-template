# Text Adventure

## Where to work

Open the file **`src/index.ts`**.

That is your file. It is the only file you need to touch, and everything
you write goes in there.

## Running it

In the terminal, type:

```
npm start
```

To stop it, press **Ctrl** and **C** together.

## Saving your work

Your changes save in the cloud as you type. To keep a copy of your own,
use the **Source Control** icon on the left, write a short message, then
click **Commit** and **Publish Branch**.
